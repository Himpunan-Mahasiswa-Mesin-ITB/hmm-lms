## Managing Users

Open **Users** from the sidebar (User Management group).

![Users page](/images/docs/admin-guide/users.png)

The table shows each member's **User** (name and email), **NIM**, **Role**, number of **Courses** and **Attempts**, the date they **Joined**, and an **Actions** column with three icon buttons:

| Icon | Action |
| --- | --- |
| 👁 Eye | View **User Details** |
| ✏️ Pencil | **Edit User** |
| 🗑 Trash | **Delete User** |

## Finding Users

- Type in *Search users by name, email, or NIM...*.
- Use the **Role** dropdown (**All Roles**, **Admin**, **Student**) to filter.
- Use the pagination controls at the bottom for more results.

## Viewing Details

Click the **eye** icon on a row to see:

- **Academic Information** — Faculty, Program, NIM.
- **Enrolled Courses**.
- **Recent Learning Sessions**.
- **Recent Tryout Attempts**.

## Editing a User

<Steps>
<Step>

Click the **pencil** icon on the user's row to open the **Edit User** dialog.

</Step>
<Step>

Update the name, **Role**, and academic fields such as NIM, Faculty, Program and Position.

</Step>
<Step>

Click **Save**. *User updated successfully* confirms the change.

</Step>
</Steps>

## Extra Actions

The **Edit User** dialog also has:

- **Hash Password** (under **Extra Actions**) — re-hashes a legacy password.
- **Reset password** (button at the bottom, next to Save) — after you confirm, it generates a new password and shows it once in a message (*Password reset. New password: ...*). Share it securely with the member and ask them to change it.

## Deleting a User

Click the **trash** icon on the row and confirm in the **Delete User** dialog.

<Callout type="error" title="Deleting is permanent">
  Deleting a user removes their enrollments, attempts and activity. Ask the user to confirm first, and prefer editing the account if you only need to change access.
</Callout>

<Callout type="warn" title="Granting admin access">
  Only give the **Admin** role to trusted members. Roles such as BP and Superadmin are described in [Special Roles](/docs/admin/special-roles).
</Callout>
