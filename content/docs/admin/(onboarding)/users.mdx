## Managing Users

Open **Users** from the sidebar (User Management group).

![Users page](/images/docs/admin-guide/users.png)

The table shows each member's **User** (name and email), **NIM**, **Role**, number of **Courses** and **Attempts**, the date they **Joined**, and an **Actions** menu.

## Finding Users

- Type in *Search users by name, email, or NIM...*.
- Use the **Role** dropdown (**All Roles**, **Admin**, **Student**) to filter.
- Use the pagination controls at the bottom for more results.

## Viewing Details

Open the actions menu on a row and choose **User Details** to see:

- **Academic Information** — Faculty, Program, NIM.
- **Enrolled Courses**.
- **Recent Learning Sessions**.
- **Recent Tryout Attempts**.

## Editing a User

<Steps>
<Step>

Open the actions menu on the user's row and choose **Edit User**.

</Step>
<Step>

Update the name, **Role**, and academic fields such as NIM, Faculty, Program and Position.

</Step>
<Step>

Save. *User updated successfully* confirms the change.

</Step>
</Steps>

## Extra Actions

Under **Extra Actions** in the row menu:

- **Reset password** — generates a new password and shows it once in a message (*Password reset. New password: ...*). Share it securely with the member and ask them to change it.
- **Hash password** — re-hashes a legacy password.

## Deleting a User

Choose **Delete User** from the row menu and confirm in the dialog.

<Callout type="error" title="Deleting is permanent">
  Deleting a user removes their enrollments, attempts and activity. Ask the user to confirm first, and prefer editing the account if you only need to change access.
</Callout>

<Callout type="warn" title="Granting admin access">
  Only give the **Admin** role to trusted members. Roles such as BP and Superadmin are described in [Special Roles](/docs/admin/special-roles).
</Callout>
