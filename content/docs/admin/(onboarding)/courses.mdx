## Managing Courses

Open **Courses** in the sidebar (Content Management group) to see every course. Click a course to open it, or use the create button to add a new one.

![Courses list](/images/docs/admin-guide/courses.png)

## Creating a Course

<Steps>
<Step>

### Open the form

Click **Create Course** on the Courses page.

![Create course](/images/docs/admin-guide/courses-create.png)

</Step>
<Step>

### Fill in the basics

- **Course Title** and **Class Code** (the unique identifier students see).
- **Lecturers** — for example *Abdul Hakim Masyhur, Yunendar Handoko*.
- **Description**.
- **Cover Image** — upload an image; a success message confirms the upload.

</Step>
<Step>

### Choose the type and scope

- **Course type**: **Mandatory**, **Optional** or **Machining**.
- **Scope**: who the course is meant for (for example Global or Machining).

</Step>
<Step>

### Create

Save the course. You are taken to the course page where you can add resources.

</Step>
</Steps>

## The Course Page

A course has six tabs along the top:

| Tab | What it does |
| --- | --- |
| **Overview** | Summary of the course and quick statistics |
| **Members** | Enrolled students. Search with *Search members...* and remove members individually or with **Remove All** |
| **Resources** | Files and links students can open |
| **Tryouts** | Tryouts attached to this course |
| **Analytics** | Resource views, downloads and average score |
| **Settings** | Edit course details, and the **Danger Zone** |

### Adding resources

In the **Resources** tab, choose **File** or **Link**.

<Steps>
<Step>

**Files** — select one or more files. Give each a **title** and a **category** (E-Book, Presentation, Notes, Problems, Video, Syllabus or Other).

</Step>
<Step>

**Links** — enter a **Link title**, the **URL**, the **Source** (YouTube or Google Drive) and a **category**.

</Step>
<Step>

Use **Common Description (Optional)** to apply one description to everything you upload at once, then confirm the upload.

</Step>
</Steps>

Use *Search resources...* to find an existing resource. The Analytics tab shows how often each is viewed or downloaded.

<Callout type="error" title="Danger Zone">
  In **Settings → Danger Zone** you can delete a course. This also removes its resources and member enrollments and cannot be undone.
</Callout>
