## Managing Announcements

Open **Announcements** in the sidebar (Content Management group). Announcements appear on the student **Announcements** page and notify members.

![Announcements list](/images/docs/admin-guide/announcements.png)

## Creating an Announcement

<Steps>
<Step>

### Open the editor

Click **New Announcement** at the top-right of the Announcements page. A draft ("Untitled Announcement") is created and opens in the editor.

![Create announcement](/images/docs/admin-guide/announcements-create.png)

</Step>
<Step>

### Choose the scope

- **Global** — everyone sees it.
- **Course** — only members of the selected **Course**. A course must be chosen, or you will see *Please select a course*.

</Step>
<Step>

### Write the content

Enter a **Title** (required) and write the **Content** in the rich text editor ("Start typing your announcement..."). Use the toolbar to format text.

</Step>
<Step>

### Add images (optional)

Images can be uploaded once the announcement has been saved. If you try earlier you will see *Please save the announcement first before uploading images*.

</Step>
<Step>

### Save

Save to publish. *Announcement created successfully* confirms it.

</Step>
</Steps>

## Editing or Deleting

Each announcement card shows its author, date, scope badge (e.g. **GLOBAL**) and number of replies. Use the **pencil** icon on the card to edit it, or the **trash** icon to delete it. Deleting removes it for all students.

<Callout type="info" title="Scope tip">
  Use course-scoped announcements for class-specific news so global announcements stay relevant for everyone.
</Callout>
