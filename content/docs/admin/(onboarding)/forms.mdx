## Managing Forms

Forms are used for registrations, competitions, feedback and the student **Hotline**. Open **Forms** from the sidebar (General group).

![Forms list](/images/docs/admin-guide/forms.png)

Four cards at the top show **Total Forms**, **Published**, **Drafts** and **Total Responses**. Filter the list with the tabs **All**, **Published**, **Drafts** and **Archived**, and search by name with *Search forms by title...*. Use the **grid / list** icons on the right to change the layout.

Each form card shows its type (e.g. **Competition**), its status badge, the response count, and a **switch** you can use to publish or unpublish the form quickly. Click the card to open it.

## Form Types

| Type | Use it for |
| --- | --- |
| **Normal** | General surveys and registrations |
| **Competition** | Competition registration, with **Individual** or group entries |
| **Hotline** | Messages and complaints from students |

A form can also be scoped as **Global** or **Machining**.

## Creating a Form

<Steps>
<Step>

### Open the form builder

Click **Create Form** at the top-right of the Forms page. The **Create New Form** page has three tabs: **Questions**, **Settings** and **Managers**. A red **Form Invalid** badge at the top disappears once the required fields are filled in.

![Create form](/images/docs/admin-guide/forms-create.png)

</Step>
<Step>

### Fill in the form details (Questions tab)

Under **Form Details**, enter the **Form Title** (e.g. *Event Registration*) and a **Description**. The **Form Id** is generated for you.

</Step>
<Step>

### Choose options (Settings tab)

Open the **Settings** tab to set the **Form Type**, the **End Date & Time** after which the form closes, and:

- **Collect Email** — ask respondents for their email.
- **Multiple Submissions** — allow the same person to submit more than once.

</Step>
<Step>

### Add questions

Back on the **Questions** tab, click **Add Question**, type the question text, and pick a type:

| Question type | Respondent sees |
| --- | --- |
| Short Answer / Long Answer | A one-line or multi-line text box |
| Multiple Choice | Pick one option |
| Multiple Select | Pick several options |
| File Upload | Upload files (set **Allowed File Types** and **Maximum Number of Files**) |
| Rating | A star rating |
| Date / Time | A date or time picker |
| Name Select / NIM Select | Search and pick a member by name or NIM |
| Course Select / Event Select | Search and pick a course or event |

For choice questions, add the **Answer Options**. You can mark a question **Required** and add a placeholder or extra context.

</Step>
<Step>

### Preview and publish

Use **Form Preview** to see what respondents will see, then press **Create Form** (top-right) to save. Drafts are only visible to admins; publish when ready using the switch on the form card.

</Step>
</Steps>

## Managers

Open the **Managers** tab of the form builder to give other admins access. Use *Select an admin to add* to pick the admin, then confirm. Managers can edit the form and read its responses.

## Reading Responses

Open a form's **Responses** page. It has two views:

- **Summary** — charts and totals per question.
- **Responses** (individual) — each submission, with the respondent's name, NIM and answers.

You can add **Notes** to a response for internal tracking.

<Callout type="warn" title="Editing a live form">
  Changing or removing questions after people have already responded can make old answers hard to read. Prefer archiving a form and creating a new one.
</Callout>
