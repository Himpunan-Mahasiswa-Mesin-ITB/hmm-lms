## Managing Forms

Forms are used for registrations, competitions, feedback and the student **Hotline**. Open **Forms** from the sidebar (General group).

![Forms list](/images/docs/admin-guide/forms.png)

The list can be filtered by status using the tabs at the top: **All**, **Drafts**, **Published** and **Archived**. Use the search box (*Search forms by title...*) to find a form by name.

## Form Types

| Type | Use it for |
| --- | --- |
| **Normal** | General surveys and registrations |
| **Competition** | Competition registration, with **Individual** or group entries |
| **Hotline** | Messages and complaints from students |

A form can also be scoped as **Global** or **Machining**.

## Creating a Form

<Steps>
<Step>

### Open the form builder

Click **Create Form** on the Forms page.

![Create form](/images/docs/admin-guide/forms-create.png)

</Step>
<Step>

### Fill in the form details

Enter the **Form Title** (e.g. *Event Registration*), a description, the **Form Type**, and the **End Date & Time** after which the form closes.

</Step>
<Step>

### Choose options

- **Collect Email** — ask respondents for their email.
- **Multiple Submissions** — allow the same person to submit more than once.

</Step>
<Step>

### Add questions

Click **Add Question**, type the question text, and pick a type:

| Question type | Respondent sees |
| --- | --- |
| Short Answer / Long Answer | A one-line or multi-line text box |
| Multiple Choice | Pick one option |
| Multiple Select | Pick several options |
| File Upload | Upload files (set **Allowed File Types** and **Maximum Number of Files**) |
| Rating | A star rating |
| Date / Time | A date or time picker |
| Name Select / NIM Select | Search and pick a member by name or NIM |
| Course Select / Event Select | Search and pick a course or event |

For choice questions, add the **Answer Options**. You can mark a question **Required** and add a placeholder or extra context.

</Step>
<Step>

### Preview and publish

Use **Form Preview** to see what respondents will see, then publish. Drafts are only visible to admins.

</Step>
</Steps>

## Managers

Open the **Managers** tab of a form to give other admins access. Use *Select an admin to add* to pick the admin, then confirm. Managers can edit the form and read its responses.

## Reading Responses

Open a form's **Responses** page. It has two views:

- **Summary** — charts and totals per question.
- **Responses** (individual) — each submission, with the respondent's name, NIM and answers.

You can add **Notes** to a response for internal tracking.

<Callout type="warn" title="Editing a live form">
  Changing or removing questions after people have already responded can make old answers hard to read. Prefer archiving a form and creating a new one.
</Callout>
