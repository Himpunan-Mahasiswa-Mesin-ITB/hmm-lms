<Callout type="error" title="Use with extreme care">
  The Database page edits live production records directly. There is no undo, and changes bypass the normal forms and validation. Use the dedicated admin pages (Courses, Users, Events, …) whenever possible.
</Callout>

## Database Admin

Open **Database** from the sidebar (System group).

![Database page](/images/docs/admin-guide/database.png)

## Overview Statistics

The top of the page summarises the data: **Total Records**, the **Largest Model**, the **Active Model** you are viewing, and **Last Updated**.

## Browsing a Table

1. Pick a model (table) from the **tabs** at the top, such as *Announcement*, *Course*, *Event* or *JobVacancy*. Scroll the tab bar sideways to see all models.
2. Records load in a table. Use the **Page** controls at the bottom to move between pages.
3. Use the toolbar above the table:
   - **Search** box — search the current model.
   - **All Columns** — choose which column to search in.
   - **Cols** — show or hide columns.
   - **Refresh** — reload the data.
   - **Auto: Off** — pick an interval to refresh automatically.
   - **Export** — download the data (see below).
   - **Add …** — create a new record of the current model.

Sensitive values appear hidden (dots); click the **eye** icon to reveal them.

## Creating a Record

Click **Add …** (e.g. *Add Announcement*) to open the dialog, fill in the fields (for list fields, enter *comma-separated values*), and save.

## Editing a Record

Click the **pencil** icon in the row's **Actions** column, change the fields, then save. *Successfully updated* confirms.

## Deleting Records

- **Single record** — click the **trash** icon in the row's **Actions** and confirm.
- **Bulk** — tick the checkboxes on several rows, then use **Bulk Edit** or **Bulk Delete** in the bulk actions bar.

## Exporting

<Steps>
<Step>

Click **Export** in the toolbar.

</Step>
<Step>

Choose the options in the dialog. The format is **Excel (.xlsx)** and up to **10,000 records** can be exported at once.

</Step>
<Step>

Confirm and the file downloads, with a message showing the number of exported records.

</Step>
</Steps>

<Callout type="warn" title="Sensitive data">
  Exports contain personal data (names, emails, NIM). Store them securely and delete them when no longer needed.
</Callout>
