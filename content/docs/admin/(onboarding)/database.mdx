<Callout type="error" title="Use with extreme care">
  The Database page edits live production records directly. There is no undo, and changes bypass the normal forms and validation. Use the dedicated admin pages (Courses, Users, Events, …) whenever possible.
</Callout>

## Database Admin

Open **Database** from the sidebar (System group).

![Database page](/images/docs/admin-guide/database.png)

## Overview Statistics

The top of the page summarises the data: **Total Records**, the **Largest Model**, the **Active Model** you are viewing, and **Last Updated**.

## Browsing a Table

1. Pick a model (table) such as users, courses or events from the model selector.
2. Records load in a table with **Page** controls at the bottom.
3. Turn on **auto refresh** to keep the table up to date while others are working.

## Creating a Record

Click the create button to open the dialog, fill in the fields (for list fields, enter *comma-separated values*), and save.

## Editing a Record

Use the **Actions** column on a row and choose edit, change the fields, then save. *Successfully updated* confirms.

## Deleting Records

- **Single record** — use delete in the row's **Actions** and confirm.
- **Bulk** — tick several rows, then use **Bulk Edit** or **Bulk Delete** in the bulk actions bar.

## Exporting

<Steps>
<Step>

Click the export button.

</Step>
<Step>

Choose the options in the dialog. The format is **Excel (.xlsx)** and up to **10,000 records** can be exported at once.

</Step>
<Step>

Confirm and the file downloads, with a message showing the number of exported records.

</Step>
</Steps>

<Callout type="warn" title="Sensitive data">
  Exports contain personal data (names, emails, NIM). Store them securely and delete them when no longer needed.
</Callout>
