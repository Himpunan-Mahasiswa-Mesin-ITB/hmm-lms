The **Preferences** section of the sidebar lets you adjust the website's user interface (UI) to your liking.

![Image 11](/images/docs/user-guide/image11.png)

![Image 24](/images/docs/user-guide/image24.png)

Select **Settings** on the sidebar to open the settings page.

<Callout type="info" title="Just switching light and dark mode?">
  Use the sun/moon toggle at the top right of any page. See [Getting Around](/docs/user#getting-around).
</Callout>

## Theme

Choose a color theme preset (**Default**, **Zinc**, **Rose**, **Teal**, **Vivid Pop**, **Aurora Mix**) or **Custom**. With Custom, you can:

- Set a base color or randomize it.
- Fine-tune individual colors for both light and dark mode.
- Click **Reset custom palette** to start over.

## Typography

Set the font family and font size of the website, with a preview of the result.

## Layout Spacing

Adjust the overall spacing and density of the interface.

## Accessibility

- Turn on **Contrast** for stronger borders and focus colors.
- Set **Motion** to control animations.
- Underline links to make them easier to spot.
- Enable a thicker focus outline for keyboard navigation.

<Callout type="warn">
  Accessibility preferences are saved in your **current browser only**. Set them again if you use a different browser or device.
</Callout>

## Language

A language setting is coming soon, to make the website easier to use for those who are not fluent in Indonesian.

## Resetting

To return the UI to its default appearance, click **Reset** at the bottom of the page.
