## Introduction

### General

When you open the hmmitb.com website, you will see a display like this:

![Image 4](/images/docs/user-guide/image4.png)

Press the button above to show the sidebar. The sidebar lists all the pages that can be accessed.

![Image 23](/images/docs/user-guide/image23.png)

The dashboard section contains general information about website usage activity, such as course subjects, study duration, and website usage statistics.

![Image 6](/images/docs/user-guide/image6.png)

The Hall of Fame section contains data on the friends who use the hmmitb.com website most often and the most.

![Image 5](/images/docs/user-guide/image5.png)

## Academics

![Image 18](/images/docs/user-guide/image18.png)

The academics section contains various information relevant to academic activities, such as study materials, tryouts for exams, and a variety of scholarships.

### Courses

Courses is a feature that serves as a centralized repository of academic information, already grouped by the subjects taught in the mechanical engineering curriculum.

![Image 8](/images/docs/user-guide/image8.png)

![Image 3](/images/docs/user-guide/image3.png)

To access information in a course, such as teaching materials, exam questions, and tutorial videos, users must first enroll in the course with the following steps:

1. On the main page, open the navigation bar and find the “courses” option, and the page will switch to the courses page.
2. On the courses page, click the “all courses” button to see all available courses.
3. Choose the course matching the subject you want to enroll in.
4. Click “enroll in course” to access all the information related to that subject.

### Tryouts

Tryouts is a feature that supports users’ learning by simulating questions that may appear in college exams.

![Image 19](/images/docs/user-guide/image19.png)

![Image 12](/images/docs/user-guide/image12.png)

![Image 10](/images/docs/user-guide/image10.png)

![Image 7](/images/docs/user-guide/image7.png)

To access a tryout, make sure you have enrolled in a course first. Once enrolled, simply follow these steps:

1. Click the “Tryouts” option on the navigation bar to open the tryouts page.
2. Choose the tryout you want to attempt; for example, to prepare for the 3rd partial exam of Heat Transfer, choose Tryout UP3 Perpan.
3. A confirmation page will appear for attempting the questions; click “Start New Attempt”.
4. The questions will be displayed along with their answer choices.
5. There is a question-number selector to choose which question to work on first.
6. Finish the tryout before its time limit runs out.
7. The submit button will appear after all questions have been answered.
8. After submitting, the results of the completed tryout will be shown.

### Scholarships

Scholarships is a feature that displays information about scholarships that can be applied for to support academic activities.

![Image 2](/images/docs/user-guide/image2.png)

![Image 16](/images/docs/user-guide/image16.png)

To view or apply for a scholarship, follow these steps:

1. Select the “scholarships” option on the navigation bar to go to the scholarships page.
2. The scholarships page lists the scholarships currently available.
3. Click “details” to show more complete information about the scholarship you want to learn about.
4. The scholarship information includes benefits and requirements for applicants.
5. Click “apply now” to register through the scholarship provider’s website.

## Himpunan

Himpunan is a feature containing various information related to HMM ITB, including event schedules, announcements, M-Opportunity, and Hotline.

![Image 22](/images/docs/user-guide/image22.png)

### Events

![Image 13](/images/docs/user-guide/image13.png)

![Image 14](/images/docs/user-guide/image14.png)

To view events, follow these steps:

1. Select the “events” option on the navigation bar to go to the events page
2. The events page displays all existing events; in the top-left corner you can choose to view all events (all events), your personal events (my events), and course events
3. You can click the event you want to see more detailed information about it.
4. For some events, there is attendance that you can mark as present by checking in on the attendance bubble.

### Announcements

![Image 15](/images/docs/user-guide/image15.png)

To go to announcements, follow these steps:

1. Select the “announcements” option on the navigation bar to go to the announcements page
2. You will see the latest announcements about HMM ITB activities. To see an announcement in more detail, click “see more” so the announcement can be seen in full
3. You can also reply to the announcement by clicking the “reply” button

### M-Opportunity

![Image 9](/images/docs/user-guide/image9.png)

To go to M-Opportunity, follow these steps:

1. Select the “M - Opportunity” option on the navigation bar to go to the M-Opportunity page
2. You will see sorting options for M - Opportunity information, sorted by location, level (intern, junior, mid, senior), and type (intern, part-time, full-time, contract). You can also sort by the related field through stream

### Hotline

![Image 25](/images/docs/user-guide/image25.png)

To go to Hotline, follow these steps:

1. Select the “Hotline” option on the navigation bar to go to the hotline page
2. You will see information about the reporting flow for a particular aspect. To submit a report, click “open form” to fill in a report on the topic you want to report

## Preference

Preference is a display settings (User Interface/UI) feature on the HMM ITB website so it can be adjusted to your preferences.

![Image 26](/images/docs/user-guide/image26.png)

### Settings

![Image 11](/images/docs/user-guide/image11.png)

![Image 24](/images/docs/user-guide/image24.png)

To go to Settings, follow these steps:

1. Select the “Settings” option on the navigation bar to go to the settings page
2. The settings page shows various information about the UI settings that can be made. First, there is an option to enable and disable the settings at the very top. To change it, click “enable”/”disable”
3. Next, there is a choice of website color themes that can be adjusted to your preferences.
4. You can also set the font and text size of the website in the “typography” section
5. You can also adjust the layout spacing to see the interface more easily.
6. In the accessibility section, you can adjust various parameters to make operating the website more comfortable. You can set contrast to show borders more clearly, motion so that scrolling moves slower or faster, underline on links, and the outline shown when using the on-display keyboard
7. In the future, we will also provide a language setting to make it easier for users who are not fluent in Indonesian to operate the website.
8. If you want to return the UI to its default appearance, click the “reset” button at the bottom right
