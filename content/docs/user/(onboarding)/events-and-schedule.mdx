## Events & Schedule Management

Stay organized and never miss important dates with the comprehensive events and scheduling features on HMM LMS. This guide covers how to view, manage, and interact with events across the platform.

<Callout type="info" title="Calendar Integration">
  Your events and schedule are integrated with your dashboard, providing a unified view of all your
  important dates and deadlines.
</Callout>

## Events Overview

### 📅 **Event Types**

The platform supports multiple event categories:

- **Personal Events**: Your own scheduled activities and deadlines
- **Course Events**: Academic schedules related to your enrolled courses
- **Global Events**: Organization-wide announcements and activities
- **Machining Events**: Specialized events for specific programs

### 🎯 **Event Access**

Events can be accessed through:

- **Events Page**: Dedicated section for browsing all events
- **Schedule Page**: Calendar view with personal scheduling tools
- **Dashboard**: Quick preview of upcoming events
- **Course Pages**: Course-specific events and deadlines

## Events Page

### 📋 **Events Navigation**

The Events page is organized into tabs:

#### **All Events Tab**

- Browse all publicly available events
- View organization-wide activities
- Access open events and announcements
- Filter by event type and date

#### **My Events Tab**

- View your personal event registrations
- See events you've created or joined
- Track your personal schedule
- Manage your event participation

#### **Course Events Tab**

- Events specific to your enrolled courses
- Academic deadlines and milestones
- Course-related activities
- Instructor-led sessions

### 🎴 **Event Cards**

Each event displays key information:

- **Event Title**: Name and brief description
- **Date & Time**: When the event takes place
- **Location**: Physical or virtual venue
- **Event Type**: Category classification
- **Registration Status**: Whether you're registered

## Schedule Page

### 🗓️ **Calendar Interface**

The Schedule page provides a comprehensive calendar view:

- **Monthly Overview**: See all events in a month
- **Daily Details**: Click on dates for specific event information
- **Event Filters**: Show/hide different event types
- **Quick Navigation**: Easily jump between months

### 🎨 **Event Categories**

Different event types are color-coded:

- **Personal Events**: Green-coded for your personal schedule
- **Course Events**: Blue-coded for academic activities
- **Global Events**: Purple-coded for organization events

### 🔍 **Filter Options**

Customize your calendar view:

- **Scope Filter**: Toggle between personal, course, and global events
- **Date Range**: Focus on specific time periods
- **Event Types**: Show only certain event categories
- **Active Only**: View upcoming or ongoing events

## Event Features

### 📖 **Event Details**

When viewing an event, you can see:

- **Full Description**: Complete event information
- **Timing**: Start and end times
- **Location**: Physical address or virtual link
- **Attendees**: Who else is registered (if applicable)
- **Requirements**: Any prerequisites or materials needed

### 🎯 **Event Actions**

Depending on the event type and your permissions:

- **Register**: Sign up for upcoming events
- **Add to Calendar**: Sync with external calendar apps
- **Set Reminders**: Get notifications before events
- **View Details**: Access comprehensive event information

### 📱 **RSVP System**

Some events include RSVP functionality:

- **RSVP Deadline**: Last date to respond
- **Approval Process**: May require organizer approval
- **Attendance Tracking**: Monitor your participation history
- **Cancellation Policy**: Rules for canceling registrations

## Personal Scheduling

### ➕ **Creating Events**

If you have permission, you can create personal events:

- **Event Details**: Set title, description, and timing
- **Location**: Specify physical or virtual location
- **Scope**: Choose personal, course, or global visibility
- **Recurrence**: Set up repeating events if needed

### ✏️ **Managing Events**

Edit and manage your created events:

- **Update Details**: Modify event information
- **Change Timing**: Reschedule events as needed
- **Cancel Events**: Remove events you no longer need
- **Delete Events**: Permanently remove from calendar

### 🔔 **Event Reminders**

Stay informed with notifications:

- **Email Alerts**: Get email notifications before events
- **Push Notifications**: Receive in-app reminders
- **Custom Timing**: Set when to receive reminders
- **Multiple Reminders**: Set several reminder times

## Course Events

### 🎓 **Academic Scheduling**

Course events include:

- **Class Sessions**: Regular meeting times for courses
- **Exam Dates**: Scheduled assessments and tryouts
- **Assignment Deadlines**: Due dates for coursework
- **Office Hours**: Instructor availability periods

### 📚 **Course Integration**

Course events automatically sync with:

- **Course Enrollments**: Events appear when you enroll
- **Course Updates**: New events added by instructors
- **Progress Tracking**: Events tied to course milestones
- **Notifications**: Alerts for course-related deadlines

## Best Practices

### 🎯 **Event Management**

1. **Regular Check-ins**: Review your schedule weekly
2. **Set Reminders**: Configure notifications for important events
3. **Plan Ahead**: Use the calendar to prepare for busy periods
4. **Stay Organized**: Color-code and categorize your events

### 📅 **Time Management**

- **Block Study Time**: Schedule dedicated learning periods
- **Avoid Conflicts**: Check for overlapping events
- **Prioritize**: Focus on high-impact events first
- **Buffer Time**: Leave time between events

### 🔔 **Notification Strategy**

- **Critical Events**: Set multiple reminders for important dates
- **Routine Events**: Single reminders may suffice
- **Advance Notice**: Set reminders well in advance
- **Follow-up**: Reminders for post-event tasks

## Event Troubleshooting

### 🐛 **Common Issues**

- **Events Not Showing**: Check your filter settings and permissions
- **Calendar Sync Problems**: Verify your internet connection
- **Missing Events**: Ensure you're enrolled in relevant courses
- **Time Zone Issues**: Check your profile time zone settings

### 🔧 **Technical Solutions**

- **Refresh Page**: Reload if events don't appear
- **Clear Cache**: Remove browser data if display issues persist
- **Check Permissions**: Verify you have access to the events
- **Update Browser**: Ensure you're using a supported browser

### 📞 **Getting Help**

- **Event Access**: Contact event organizers for permission issues
- **Technical Problems**: Reach out to platform support
- **Course Events**: Check with your instructors
- **General Questions**: Consult our [FAQ section](/docs/user/faq)
